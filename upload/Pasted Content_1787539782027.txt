Tu es un architecte logiciel senior, développeur full-stack, expert UI/UX, e-commerce, logistique alimentaire, gestion d’entrepôt, paiements sécurisés et applications web internationales.

Ta mission est de concevoir et développer de bout en bout une plateforme e-commerce alimentaire africaine appelée « Je mange Africain ».

Ne réalise pas une simple maquette statique. Construis une application complète, professionnelle, fonctionnelle, sécurisée, responsive, évolutive et prête à être déployée en production. Aucun bouton ne doit être décoratif, aucun écran ne doit être vide et aucun parcours essentiel ne doit être simulé.

# 1. IDENTITÉ DU PROJET

Nom exact de la marque : « Je mange Africain »

L’entreprise est installée en France et vend ses propres produits alimentaires africains. Elle gère elle-même :

* Les fournisseurs ;

* Smartphone ;

* Ordinateur ;
* Application web installable de type PWA.

Prévoir une architecture permettant de créer ultérieurement des applications Android et iOS sans reconstruire tout le système.

La devise initiale est l’euro.

La plateforme doit être intégralement disponible en :

* Français ;

Le nom de la marque « Je mange Africain » ne doit jamais être traduit.

# 2. MODÈLE ÉCONOMIQUE

La plateforme appartient à une seule entreprise.

Il ne s’agit pas d’une marketplace ouverte.

Pour le lancement, il ne doit y avoir :

* Aucun vendeur externe ;
* Aucun portail marchand ;
* Aucune commission ;
* Aucun partage de paiement ;
* Aucun portefeuille vendeur ;
* Aucun système d’escrow ;
* Aucune publication libre de produits ;
* Aucun produit cosmétique, vestimentaire ou sans rapport avec la cuisine.

L’entreprise est l’unique vendeuse. Elle achète ou importe les produits, les stocke, les commercialise et organise leur livraison.

Prévoir techniquement une évolution future vers la vente professionnelle, mais ne pas activer un espace vendeur externe.

# 3. OBJECTIF PRINCIPAL

Créer une grande épicerie africaine digitale permettant aux personnes vivant en France puis en Europe de retrouver facilement des produits africains authentiques.

La plateforme doit aller beaucoup plus loin qu’un site e-commerce classique.

Son principal avantage concurrentiel sera un moteur de recettes intelligentes permettant au client de :

1. Choisir une sauce, un plat, une boisson ou un dessert ;
2. Indiquer le nombre de personnes ;
3. Personnaliser la recette ;
4. Obtenir automatiquement les ingrédients nécessaires ;
5. Voir les quantités exactes ;
6. Voir les conditionnements disponibles ;
7. Connaître le coût total ;
8. Connaître le coût par personne ;
9. Modifier librement le panier ;
10. Commander tous les ingrédients en une seule opération.

La promesse centrale est :

« Tous les produits authentiques de la cuisine africaine, livrés chez vous. »

Version anglaise :

« Authentic African cooking essentials, delivered to your door. »

## Parcours du configurateur

Le client choisit une recette ou écrit une demande en langage naturel.

Exemples :

« Je veux préparer du placali sauce graine pour 8 personnes. »

« I want to prepare placali with palm nut sauce for 8 people. »

Demander ensuite :

* Restrictions alimentaires ;
* Budget maximum ;
* Ingrédients déjà disponibles à la maison.

## Calcul

Pour chaque ingrédient :

Quantité nécessaire = quantité de référence × nombre de personnes demandé ÷ nombre de portions de référence.

Le système doit ensuite :

* Convertir les unités ;
* Gérer grammes, kilogrammes, millilitres, litres et unités ;
* Identifier les variantes de produits disponibles ;
* Vérifier le stock ;
* Calculer le meilleur conditionnement ;
* Arrondir le nombre de paquets ;
* Limiter le gaspillage ;
* Calculer les restes ;
* Proposer les alternatives ;
* Consolider les ingrédients identiques de plusieurs recettes ;
* Retirer les ingrédients déjà possédés ;
* Calculer le coût réel d’achat ;
* Calculer le coût par personne.

Afficher distinctement :

* Quantité nécessaire ;
* Quantité réellement achetée ;
* Nombre de paquets ;
* Quantité restante après préparation ;
* Prix du produit ;
* Coût total ;
* Coût par personne.

Exemple :

* Quantité nécessaire : 600 g ;
* Format disponible : 400 g ;
* Quantité proposée : 2 boîtes ;
* Quantité achetée : 800 g ;
* Reste estimé : 200 g.

   604→## Calcul
   605→
   606→Pour chaque ingrédient :
   607→
   608→Quantité nécessaire = quantité de référence × nombre de personnes demandé ÷ nombre de portions de référence.
   609→
   610→Le système doit ensuite :
   611→
   612→* Convertir les unités ;
   613→* Gérer grammes, kilogrammes, millilitres, litres et unités ;
   614→* Identifier les variantes de produits disponibles ;
   615→* Vérifier le stock ;
   616→* Calculer le meilleur conditionnement ;
   617→* Arrondir le nombre de paquets ;
   618→* Limiter le gaspillage ;
   619→* Calculer les restes ;
   620→* Proposer les alternatives ;
   621→* Consolider les ingrédients identiques de plusieurs recettes ;
   622→* Retirer les ingrédients déjà possédés ;
   623→* Calculer le coût réel d’achat ;
   624→* Calculer le coût par personne.
   625→
   626→Afficher distinctement :
   627→
   628→* Quantité nécessaire ;
   629→* Quantité réellement achetée ;
   630→* Nombre de paquets ;
   631→* Quantité restante après préparation ;
   632→* Prix du produit ;
   633→* Coût total ;
   634→* Coût par personne.
   635→
   636→Exemple :
   637→
   638→* Quantité nécessaire : 600 g ;
   639→* Format disponible : 400 g ;
   640→* Quantité proposée : 2 boîtes ;
   641→* Quantité achetée : 800 g ;
   642→* Reste estimé : 200 g.

    46→    46→# 2. MODÈLE ÉCONOMIQUE
    47→    47→
    48→    48→La plateforme appartient à une seule entreprise.
    49→    49→
    50→    50→Il ne s’agit pas d’une marketplace ouverte.
    51→    51→
    52→    52→Pour le lancement, il ne doit y avoir :
    53→    53→
    54→    54→* Aucun vendeur externe ;
    55→    55→* Aucun portail marchand ;
    56→    56→* Aucune commission ;
    57→    57→* Aucun partage de paiement ;
    58→    58→* Aucun portefeuille vendeur ;
    59→    59→* Aucun système d’escrow ;
    60→    60→* Aucune publication libre de produits ;
    61→    61→* Aucun produit cosmétique, vestimentaire ou sans rapport avec la cuisine.
    62→    62→
    63→    63→L’entreprise est l’unique vendeuse. Elle achète ou importe les produits, les stocke, les commercialise et organise leur livraison.
    64→    64→
    65→    65→Prévoir techniquement une évolution future vers la vente professionnelle, mais ne pas activer un espace vendeur externe.

    67→    67→# 3. OBJECTIF PRINCIPAL
    68→    68→
    69→    69→Créer une grande épicerie africaine digitale permettant aux personnes vivant en France puis en Europe de retrouver facilement des produits africains authentiques.
    70→    70→
    71→    71→La plateforme doit aller beaucoup plus loin qu’un site e-commerce classique.
    72→    72→
    73→    73→Son principal avantage concurrentiel sera un moteur de recettes intelligentes permettant au client de :
    74→    74→
    75→    75→1. Choisir une sauce, un plat, une boisson ou un dessert ;
    76→    76→2. Indiquer le nombre de personnes ;
    77→    77→3. Personnaliser la recette ;
    78→    78→4. Obtenir automatiquement les ingrédients nécessaires ;
    79→    79→5. Voir les quantités exactes ;
    80→    80→6. Voir les conditionnements disponibles ;
    81→    81→7. Connaître le coût total ;
    82→    82→8. Connaître le coût par personne ;
    83→    83→9. Modifier librement le panier ;
    84→    84→10. Commander tous les ingrédients en une seule opération.

   604→   604→## Calcul
   605→   605→
   606→   606→Pour chaque ingrédient :
   607→   607→
   608→   608→Quantité nécessaire = quantité de référence × nombre de personnes demandé ÷ nombre de portions de référence.
   609→   609→
   610→   610→Le système doit ensuite :
   611→   611→
   612→   612→* Convertir les unités ;
   613→   613→* Gérer grammes, kilogrammes, millilitres, litres et unités ;
   614→   614→* Identifier les variantes de produits disponibles ;
   615→   615→* Vérifier le stock ;
   616→   616→* Calculer le meilleur conditionnement ;
   617→   617→* Arrondir le nombre de paquets ;
   618→   618→* Limiter le gaspillage ;
   619→   619→* Calculer les restes ;
   620→   620→* Proposer les alternatives ;
   621→   621→* Consolider les ingrédients identiques de plusieurs recettes ;
   622→   622→* Retirer les ingrédients déjà possédés ;
   623→   623→* Calculer le coût réel d’achat ;
   624→   624→* Calculer le coût par personne.
   625→   625→
   626→   626→Afficher distinctement :
   627→   627→
   628→   628→* Quantité nécessaire ;
   629→   629→* Quantité réellement achetée ;
   630→   630→* Nombre de paquets ;
   631→   631→* Quantité restante après préparation ;
   632→   632→* Prix du produit ;
   633→   633→* Coût total ;
   634→   634→* Coût par personne.
   635→   635→
   636→   636→Exemple :
   637→   637→
